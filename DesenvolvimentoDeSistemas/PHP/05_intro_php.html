Tópicos da Aula

  • O que é PHP? Linguagem de script do lado do servidor (Backend).
  • Sintaxe Básica: <?php ... ?>.
  • Variáveis: Começam com $ (ex: $nome). Tipagem dinâmica.
  • Tipos de Dados: String, Integer, Float, Boolean, Array, Null.

Variáveis (bem simples)

Variável é uma “caixinha” que guarda um valor. Em PHP, sempre começa com $.

HTML (variaveis.html)

<form action="variaveis.php" method="post">
  <label>Nome:</label>
  <input type="text" name="nome">

  <label>Idade:</label>
  <input type="number" name="idade">

  <button type="submit">Enviar</button>
</form>
PHP (variaveis.php)

<?php
$nome = $_POST["nome"] ?? "";
$idade = (int)($_POST["idade"] ?? 0);
$mensagem = "Olá, " . $nome;

echo $mensagem . "<br>";
echo "Idade: " . $idade;
?>

Exemplo (POST): Média

HTML (media.html)

<form action="media.php" method="post">
  <input type="number" name="nota1" step="0.01" placeholder="Nota 1">
  <input type="number" name="nota2" step="0.01" placeholder="Nota 2">
  <button type="submit">Calcular</button>
</form>
PHP (media.php)

<?php
$nota1 = (float)($_POST["nota1"] ?? 0);
$nota2 = (float)($_POST["nota2"] ?? 0);

$media = ($nota1 + $nota2) / 2;

echo "Média: " . $media . "<br>";
echo ($media >= 7) ? "Aprovado" : "Reprovado";
?>

Exemplo (POST): Ano Bissexto

HTML (bissexto.html)

<form action="bissexto.php" method="post">
  <input type="number" name="ano" placeholder="Ano">
  <button type="submit">Verificar</button>
</form>
PHP (bissexto.php)

<?php
$ano = (int)($_POST["ano"] ?? 0);

$div4 = ($ano % 4 === 0);
$div100 = ($ano % 100 === 0);
$div400 = ($ano % 400 === 0);

$ehBissexto = ($div4 && !$div100) || $div400;

echo $ehBissexto ? "É bissexto" : "Não é bissexto";
?>

Exemplo Prático: Decisão

O aluno preenche no HTML. O PHP mostra a mensagem.

HTML (decisao.html)

<form action="decisao.php" method="post">
  <label>Idade:</label>
  <input type="number" name="idade">

  <label>
    <input type="checkbox" name="cnh" value="1">
    Tem CNH
  </label>

  <button type="submit">Verificar</button>
</form>
PHP (decisao.php)

<?php
$idade = (int)($_POST["idade"] ?? 0);
$temHabilitacao = isset($_POST["cnh"]);

if ($idade >= 18 && $temHabilitacao) {
    echo "Pode dirigir!";
} elseif ($idade >= 18 && !$temHabilitacao) {
    echo "Maior de idade, mas sem CNH.";
} else {
    echo "Menor de idade.";
}
?>

Desafio (Avançado)

Dica: Use os exemplos dos slides “Média” e “Ano Bissexto” e adapte os valores.
