Equivalência • Valor-limite • Cobertura

Caixa Preta vs Caixa Branca

Caixa Preta

Você testa o sistema pelo comportamento: entradas e saídas.

  • Particionamento de equivalência
  • Valores-limite
  • Tabela de decisão

Caixa Branca

Você considera a lógica interna (fluxos, condições, caminhos).

  • Cobertura de linhas/condições
  • Caminhos básicos
  • Testes por branches

Particionamento de Equivalência (exemplo)

Regra

Se o campo “Preço” aceita valores entre 0.01 e 9999.99, as classes podem ser:

  • Válidos: 0.01 a 9999.99
  • Inválidos: <= 0
  • Inválidos: muito alto
  • Inválidos: não numérico

Como virar caso de teste

Em vez de testar mil valores, você testa 1 de cada classe:

  • 0.01 (válido)
  • -1 (inválido)
  • 100000 (inválido)
  • “abc” (inválido)

Valor-limite (onde os bugs gostam de morar)

Se uma regra diz “mínimo 3 caracteres”, você testa:

2 (inválido)
3 (válido)
4 (válido)

O valor-limite é ótimo para campos e validações (tamanho, faixa numérica, datas).
