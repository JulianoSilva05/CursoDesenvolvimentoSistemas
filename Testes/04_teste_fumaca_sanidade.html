Aula 04: Teste de Fumaça e Teste de Sanidade

Aula 04
Build quebrado? Pare cedo • Bloom: Lembrar / Aplicar

Objetivo: saber quando usar teste de fumaça (smoke) versus sanidade (sanity); montar uma suíte mínima que valida se o sistema “liga” e se o módulo alterado ainda faz o básico.

Teste de fumaça (smoke testing)

Ideia

Checagem superficial e rápida após um novo build ou deploy. Se “sair fumaça”, o sistema não está estável o suficiente para testes mais profundos — pare e corrija.

Exemplos típicos (web)

  • Servidor responde (HTTP 200 na home).
  • Login carrega e autentica usuário válido.
  • Menu principal abre e links críticos não retornam 404.
  • Um fluxo CRUD mínimo salva e lista registro.

Fumaça responde: “O build está testável?” — não substitui teste funcional completo.

Teste de sanidade (sanity testing)

Ideia

Após uma correção pontual ou mudança em um módulo, executa-se um subconjunto estreito de casos para confirmar que a área afetada ainda funciona e que o bug aparentemente sumiu.

Fumaça x Sanidade

  • Fumaça: amplo, rápido, todo o sistema “de pé”.
  • Sanidade: focado no que mudou (região do defeito / feature).

Onde isso entra no dia a dia

CI/CD (exemplo conceitual)
1) Build gera artefato
2) Deploy em ambiente de teste
3) Smoke automático ou manual (5–15 min)
4) Se PASS → testes funcionais / regressão
5) Se FAIL → dev recebe “build quebrado”, sem perder horas em teste profundo

Em equipes pequenas (como em projetos de curso), um checklist de fumaça no quadro ou no README já evita entregar trabalho que “não abre no navegador”.

Atividade: suíte de fumaça + plano de sanidade

⚠️ INDIVIDUAL. Imagine um sistema web de empréstimo de livros (login, catálogo, emprestar, devolver, multa).

Parte A — Fumaça

Escreva 10 casos de teste de fumaça no formato: ID | Passo principal | Resultado esperado (uma linha por caso).

Parte B — Sanidade

Suponha que o dev corrigiu o cálculo de multa. Escreva 5 casos de sanidade só para a área de multa/devolução (inclua 1 negativo).

Encerramento

Você aprendeu a filtrar builds ruins cedo com fumaça e a validar correções com sanidade.
