O que é teste de integração

Integração testa a conversa entre partes: front ↔ back, back ↔ banco, serviço ↔ API externa.

  • Dados corretos chegando no destino
  • Tratamento de falhas (timeout, 500)
  • Validação de contrato (campos)

Um bug clássico: front manda “codigo_de_barras” e API espera “codigo_barras”. Funciona em um lugar e quebra no outro.

Checklist de API (mínimo)

Resposta

  • Status code correto (200/201/400/401/404/500)
  • JSON válido
  • Campos esperados
  • Mensagens de erro úteis

Contrato

  • Campos obrigatórios
  • Tipos corretos (string/number)
  • Validação (faixas, formatos)
  • Idempotência quando aplicável
