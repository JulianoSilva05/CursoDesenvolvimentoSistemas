Suíte mínima • Regressão • Evidências

Teste funcional: o que o usuário consegue fazer

Foco

  • Fluxos principais (happy path)
  • Validações e erros
  • Persistência (salva mesmo?)
  • Mensagens (feedback claro)

Evidência

Para cada teste, defina o que prova o resultado:

  • print de mensagem
  • registro em tabela
  • log do servidor
  • vídeo curto do fluxo

Regressão: o que quebra quando você muda

Regressão é o conjunto de testes que você roda depois de uma alteração para garantir que o que funcionava continua funcionando.

Suíte mínima (exemplo)

  • Cadastro com dados válidos
  • Validação: campo obrigatório
  • Validação: preço inválido
  • Consulta do item cadastrado
  • Voltar e navegar sem perder contexto

Como escolher

  • Escolha o que tem mais impacto (dados, dinheiro, segurança).
  • Inclua 1 caso de erro por fluxo principal.
  • Inclua o que já quebrou antes (histórico).

Atividade 1: Montar uma suíte de regressão

⚠️ Atividade INDIVIDUAL.

Cenário

Um sistema de cadastro de produtos recebeu uma atualização para “validar preço com duas casas decimais” e “exibir mensagem de sucesso”.

Entrega

  • Defina 8 testes de regressão (título + objetivo)
  • Escolha 3 e escreva caso completo
  • Defina evidência para cada um
