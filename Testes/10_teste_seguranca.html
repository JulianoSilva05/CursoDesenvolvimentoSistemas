OWASP Top 10 (visão de testador)

A OWASP lista riscos frequentes em aplicações web. Você não precisa ser hacker: precisa reproduzir cenários conhecidos com dados controlados.

  • A01 Broken Access Control: usuário comum acessa rota/admin?
  • A03 Injection (SQL/LDAP/OS): entrada vira comando?
  • A07 Auth failures: senha fraca aceita? bloqueio após tentativas?
  • XSS: script injetado refletido ou armazenado?
  • Crypto failures: senha em texto puro? HTTP sem TLS em produção?
  • Security logging: ataque deixa rastro?

Referência oficial: OWASP Top 10 (consulte a versão atual).

SQL Injection (teste conceitual)

O que procurar

Campos que montam SQL por concatenação. Entradas de teste (em ambiente controlado):

  • ' OR '1'='1
  • ; DROP TABLE (nunca em produção real de terceiros)
  • Caracteres de escape: ' " --

Esperado seguro

Prepared statements / parametrização: entrada tratada como dado, não como comando. Erro genérico ao usuário, detalhe só em log.

XSS e sessão

XSS (Cross-Site Scripting)

Teste (laboratório): envie <script>alert(1)</script> em campo que é exibido depois. Se o script executar, há XSS (armazenado ou refletido).

Mitigação: sanitizar saída, CSP, encoding correto.

Sessão

  • Cookie com flags HttpOnly e Secure?
  • Logout invalida sessão no servidor?
  • URL com session id fixo (session fixation)?
