Meta: construir um app que conecta via Bluetooth, envia comandos e recebe telemetria com um protocolo de mensagens simples e confiável.

Bluetooth no mundo IoT

Quando usar Bluetooth

  • Controle local (curta distância)
  • Configuração inicial do dispositivo (Wi‑Fi, nome, chave)
  • Economia de energia em projetos simples

Exemplo: app controla LED, motor, relé e recebe temperatura.

Limitações (para projetar certo)

  • Alcance e interferência
  • Conexão pode cair: precisa reconectar
  • Mensagens chegam em “pedaços”: precisa delimitar

Erro clássico: esperar que o Bluetooth entregue “uma mensagem completa por vez”. Em geral, você recebe um fluxo de bytes. Use delimitador (ex: \n) e faça parsing.

Protocolo de mensagens (simples e confiável)

Regras recomendadas

  • Mensagens em texto (ASCII) para depurar rápido.
  • Um comando por linha, terminando com \n.
  • Chave:Valor (fácil de ler e parsear).
  • Confirmação opcional: dispositivo responde OK ou ERR.

Exemplos

Comandos (celular → dispositivo) LED:1\n LED:0\n FAN:80\n PING\n Respostas (dispositivo → celular) OK\n ERR:CMD\n TEMP:26.3;HUM:62;LDR:812\n PONG\n

Regra de robustez: qualquer mensagem inválida deve virar ERR e nunca travar o dispositivo.

App Inventor: componentes e blocos essenciais

Designer (componentes)

  • ListPicker (listar dispositivos pareados)
  • BluetoothClient (conectar e trocar dados)
  • Clock (polling/tempo de leitura)
  • Buttons (comandos)
  • Labels/ListView (telemetria e log)

Blocks (padrões)

when ListPickerBT.BeforePicking set ListPickerBT.Elements to BluetoothClient1.AddressesAndNames when ListPickerBT.AfterPicking call BluetoothClient1.Connect(address = ListPickerBT.Selection) set LabelStatus.Text to if BluetoothClient1.IsConnected then "Conectado" else "Falha" when ButtonLEDOn.Click call BluetoothClient1.SendText("LED:1\n")

Leitura de dados: use o Clock para checar se há bytes disponíveis e montar linhas até o \n.

Leitura de telemetria: parsing sem dor

Estratégia

  • Ter uma variável buffer (texto acumulado).
  • Em cada tick do Clock, ler texto disponível e concatenar no buffer.
  • Enquanto existir \n no buffer, separar uma linha completa.
  • Para telemetria, separar por ; e depois por :.

Pseudobloco (modelo)

global buffer = "" when Clock1.Timer if BluetoothClient1.IsConnected and BluetoothClient1.BytesAvailableToReceive > 0 set buffer to join buffer (call BluetoothClient1.ReceiveText(-1)) while buffer contains "\n" set line to text before first "\n" set buffer to text after first "\n" call ProcessarLinha(line) to ProcessarLinha(line) if line starts with "TEMP:" // parse e atualiza UI

Não confie no dado: se um valor vier vazio ou não numérico, registre no log e ignore a linha.

Depuração (o que testar primeiro)

Checklist rápido

  • Dispositivo está pareado no celular?
  • Endereço selecionado é o correto?
  • Conectou? (IsConnected true)
  • Você está enviando \n no final?
  • O dispositivo está respondendo OK?

Testes de robustez

  • Desconectar e reconectar sem travar o app
  • Receber mensagem quebrada e reconstruir pelo buffer
  • Enviar comando inválido e tratar ERR

Atividade 1 (4h): App “Controle Remoto” (com protocolo)

⚠️ Importante: Atividade INDIVIDUAL. Não saia desta tela. Entregue pelo botão de envio.

Requisitos (mínimo)

  • ListPicker para escolher o dispositivo Bluetooth.
  • Botões: LED ON, LED OFF, PING.
  • Enviar comandos terminando com \n.
  • Mostrar status de conexão e um log de ações.
  • Se não estiver conectado, bloquear envio e avisar na tela.

  • Implementar botão “Reconectar”.
  • Guardar o último endereço no TinyDB.
  • Confirmar resposta OK / ERR.

Atividade 2 (4h): Painel de telemetria (parsing)

Entrada esperada

O dispositivo envia linhas como:

TEMP:26.3;HUM:62;LDR:812\n

Seu app deve mostrar: temperatura, umidade e luminosidade, além de registrar as linhas recebidas.

Regras

  • Usar buffer e delimitar por \n.
  • Se faltar algum campo, registrar “linha incompleta”.
  • Se valor não for numérico, ignorar e registrar no log.
  • Exibir alerta se TEMP > limite (definido pelo usuário).
